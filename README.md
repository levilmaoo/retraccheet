# Simulation Lab

Standalone Windows x64 player-visualization and camera simulator with complete simulated-player controls.

**Fortnite 14.60 live integration is unavailable and untested.** No verified SDK, game-state interface, or offsets were supplied. Anti-cheat bypass and stealth injection are not implemented.

The [Windows CI build passed](https://github.com/levilmaoo/retraccheet/actions/runs/38496865969): 20 automated logic tests, source GUI smoke testing, AMD64 executable verification, and packaged GUI smoke testing. Download the latest successful build from [Actions](https://github.com/levilmaoo/retraccheet/actions/workflows/simulation-lab-windows.yml).

See [the Windows tester guide](simulation-lab/README.md) for controls, configuration, build steps, and the manual acceptance checklist. Windows 10/11 visual acceptance remains pending.
