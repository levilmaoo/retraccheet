# Simulation Lab

Standalone Windows x64 player-visualization and camera simulator.

**Fortnite 14.60 live integration is unavailable and untested.** No verified SDK, game-state interface, or offsets were supplied. Anti-cheat bypass and stealth injection are not implemented.

Source, controls, build steps, and the Windows tester checklist are in [simulation-lab/README.md](simulation-lab/README.md). The Windows CI workflow builds and smoke-tests the executable before uploading an artifact.

Current validation: 20 local automated logic tests passed; Windows build pending.
